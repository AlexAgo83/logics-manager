Lightweight functional specs derived from backlog/tasks. Created on demand via `logics-manager assist spec-first-pass`.

Specs use explicit `Status` indicators so they can move through the same corpus filters and closeout views as product briefs and ADRs.

Allowed statuses:

- `Draft`
- `Ready`
- `In progress`
- `Done`
- `Validated`
- `Settled`
- `Archived`

Use `Settled` when a spec is no longer active but should remain as retained functional context.
